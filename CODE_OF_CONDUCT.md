# Code of conduct

Be respectful, specific, and safety-conscious.

This project handles microphones, credentials, text injection, and network services. Do not pressure contributors to share API keys, private audio, transcripts, Wi-Fi credentials, or screenshots containing personal data. Security reports belong in the private advisory flow.

Harassment, discriminatory language, deliberate credential disclosure, and attempts to use the project to inject text into systems without authorization are not acceptable.

Maintainers may remove content or restrict participation when behavior makes the project unsafe. For a conduct concern, contact the repository maintainers privately.
