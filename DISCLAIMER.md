## Speech recognition can be wrong

ASR providers can hallucinate, omit words, misrecognize names or numbers, add punctuation, or return different partial and final text. Always review generated text before relying on it. Do not use the project as the sole control path for safety-critical, medical, financial, legal, or industrial systems.

## Text injection can affect the wrong application

The bridge types into a foreground text field through platform APIs or a clipboard fallback. Window focus, permissions, timing, elevated processes, input methods, and application-specific controls can change the result. Keep the foreground-window guard enabled unless you fully understand the risk.
